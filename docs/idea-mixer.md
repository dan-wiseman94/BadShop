# Idea mixer

Open **Images & directions → Idea mixer**. Enter a subject or leave it blank to refer to your
attached images. Choose any joke, setting, era, or format to lock that choice; leave the others
on **Any**. **Mix six ideas** creates up to six briefs from the available combinations.

The mixer uses eight joke mechanisms, eight settings, six eras, and the actual layout catalog.
Each batch favors different choices across unlocked dimensions and skips the last 48 combinations
while the mixer remains open. If every combination for the selected locks has been shown, it
reports that and permits repeats. Closing or leaving the mixer resets this temporary history.
Reopening starts a fresh shuffle. This is separate from the project's **Recent choices** and chat
**Novelty** controls.

**Read the full brief** shows the exact text. **Add brief to chat** appends it to any existing draft
and closes the panel; it does not send a message, search the web, or create an image. Existing
attachments remain selected. Review the draft and send it when ready. **Prepare a source search**
opens Find images with a background query, ready for you to search.

The mixer runs locally and does not call an LLM. Its search suggestions are suggestions, not source
results. Actual source discovery and composition still use the normal inspect/import/tool workflow.
