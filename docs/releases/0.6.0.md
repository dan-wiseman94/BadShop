# BadShop 0.6.0 — Durable projects and modernized runtime

This release modernizes project storage, recovery, provider context and large-history
workflows while preserving BadShop's deterministic cut-and-paste engine.

## Changes

- Separate artifact-use identities from shared image bytes, preserving provenance
  when the same image appears in multiple imports, steps or branches.
- Migrate projects to schema 6 and recovery storage to version 2, with verified,
  non-overwriting rollback copies for supported older formats.
- Persist operation intents and receipts so reconnecting or retrying a lost reply
  does not repeat a pending or completed side effect. Publish completion after
  storage commits, and expose storage and operation diagnostics.
- Bound provider conversation and image context, scope continuation state to its
  document/provider, and show reported usage and actionable retry advice.
- Deliver binary media with bounded caches, window long histories and page saved
  materials. Improve worker limits, cancellation and temporary-file cleanup.
- Fix managed CLI startup when an authorization token begins with a dash.

## Upgrading and compatibility

Back up important `.badshop` files before upgrading. This version reads project
schemas 1–6 and writes schema 6. Older releases may refuse newly saved projects;
use the preserved older-format copy or your own backup when rolling back. See
[project compatibility and recovery](../compatibility.md#project-compatibility-and-recovery).

Windows publisher and macOS notarization warnings remain expected for this unsigned
v1 distribution. Updater signatures are separate from OS signing. Debian and Flatpak
users update through their package manager or a new download.

Paid/live provider checks are user-owned and were not run for the modernization.
Gemini CLI remains experimental. The [implementation ledger](../architecture-modernization-progress.md)
records source verification and its limits; installer acceptance is recorded separately
for the exact release candidate. No universal performance or memory guarantee is implied.
