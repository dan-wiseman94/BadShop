# BadShop 0.7.0 — Quick Ideas and Edit workspace

- Revise a Quick Idea in place or continue the same draft in Edit. Select recorded
  pictures on the canvas and move them before applying the edit.
- Find tools by task, browse Materials in context, and use Versions to compare
  takes without switching away from the current one.
- Preview one step or the final result. Apply a local edit and replay its later
  steps as one undoable operation. Recovery keeps the previous picture if replay
  is interrupted.
- Share the selected saved image, choose a destination, or export an editable
  remix. Save project keeps the editable document.
- Classic, XP, and Terminal use era-specific styles. The workspace adapts to
  narrower windows and higher text scale.

## Upgrading

Back up important `.badshop` files before upgrading. This release reads project
schemas 1–6 and writes schema 6. See [project compatibility and recovery](../compatibility.md#project-compatibility-and-recovery).

Windows publisher and macOS notarization warnings remain expected. Updater
signatures are separate from operating-system signing. Debian and Flatpak users
update through their package manager or a new download.
