# Getting help

Report ordinary bugs in [BadShop issues](https://github.com/dan-wiseman94/BadShop/issues).
For suspected vulnerabilities, follow [SECURITY.md](../SECURITY.md) before posting details.

Include the app version, operating system/architecture, installation format, exact action,
expected result and actual result. For AI issues include the provider/model and CLI version,
whether an image was attached, and whether the failure also occurs with a manual tool.
Copy diagnostics from the app, review them for private information, and attach the smallest
non-sensitive reproduction. Never include API keys, authentication tokens, private photos,
or an unreviewed project archive. A screenshot of a toast alone is less useful than the
actual error and steps that led to it.

If a task stalls, use Stop or Cancel, retain the current project, and retry with a smaller image
or the manual workflow. If the core disconnects, use the offered reconnect/restart/recovery
controls. Save recovered work under a new filename until you have checked it. Unsupported
HEIC images should be converted to PNG/JPEG first; older releases also require conversion
for AVIF. Model download and memory requirements
are listed in [compatibility.md](compatibility.md).

There is currently no published paid-support SLA, subscription promise, hosted-generation quota,
or refund policy in this repository. Before selling a pilot, publish the actual price, supported
platforms, support contact, scope/duration, refund terms and provider costs. The product study is
a proposal; it does not create those customer commitments on the owner's behalf.
