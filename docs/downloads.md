# Download BadShop

**[Open the latest stable release](https://github.com/dan-wiseman94/BadShop/releases/latest).**
Choose the installer for your computer from its Assets list. Check the release notes
for the features included; source documentation can describe newer work.

| Computer | File to choose | Install help |
| --- | --- | --- |
| Windows 64-bit Intel/AMD | `badshop_…_x64-setup.exe` | [Windows](windows.md) |
| Apple Silicon Mac, macOS 14+ | `badshop_…_aarch64.dmg` | [macOS](macos.md) |
| Intel Mac, macOS 14+ | `badshop_…_x64.dmg` | [macOS](macos.md) |
| Linux x86-64 | `badshop_…_amd64.AppImage`, `.deb`, or `badshop.flatpak` | [Linux builds](releasing.md#local-development) |

The release supplies `SHA256SUMS` for checking downloads. `.sig`, `.sbom.json` and
`latest.json` files are signatures, inventories and updater metadata, not installers.
See the platform guide for current publisher/notarization warnings. Do not infer OS
code signing from the presence of updater signatures.

After installation, choose **Start with a quick idea**. Use the free pigeon or your
own picture, change a punchline, then copy the result. Manual editing needs no AI
account. Optional background-removal models and AI providers have separate setup.
See [requirements and formats](compatibility.md).

For previews of unreleased work, use the [nightly guide](releasing.md#nightly-builds).
For this checkout's newest features, follow [source setup](development.md) and
[playful workflows](playful-workflows.md). Source builds are development builds.
