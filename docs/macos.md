# badshop on Mac

badshop runs on macOS 14 or newer. Choose the download for your Mac's processor.

1. Open **Apple menu → About This Mac**.
   If **Processor** says **Intel**, choose the **Intel Mac** download.
   If **Chip** says **Apple M1**, **M2**, or another M-series chip, choose **Apple Silicon**.
2. Open the [latest release](https://github.com/dan-wiseman94/BadShop/releases/latest)
   and click the download for that processor.
3. Open the downloaded `.dmg`, drag **badshop** to **Applications**, then open it from
   **Applications**. Choose **Edit a photo without AI** to start with your own photo.

If Finder says the application “is not supported on this Mac,” check the processor
choice in step 1 and download the matching disk image. For example, an Intel Core i7
MacBook Air running macOS Sequoia needs the Intel Mac download.

This release is unnotarized. If macOS asks about the developer, follow
[Apple's instructions for opening downloaded apps](https://support.apple.com/en-us/102445)
after checking that your download came from this repository.

Use **⌘S** to save an editable project and **⌘O** to reopen it. To share a picture,
show the version you want on the canvas and click **Export**.
