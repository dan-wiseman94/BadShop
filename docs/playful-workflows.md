# Make a running joke

These controls describe the source checkout after 0.4.3. See [downloads](downloads.md)
for released installers. Quick ideas needs no AI account or model download.

## Start with someone you know

Choose **Try my picture in every idea**. All six thumbnails show your picture before
you create anything. Choose a format, change the words and make the image. Previews
do not add work to History. Use **Picture for previews** to try a cutout or another result.

Under **Your cast of characters**, name the selected picture, add an expression and
collection, then keep it. A character can have several saved expressions. Use it in
another project without finding the original again. Edit or remove library entries
without removing copies already used in projects. Export a collection as a `.badpack`;
packs include the selected library entries' original images and source metadata.

## Make more than one joke

**Make a scene: surprises & reaction sets** offers Worst workplace, Extremely local
news and Petty victories. Preview three formats or six reactions before creating them.
**Keep my current headline and punchline exactly** preserves your words, including an
empty punchline. Uncheck it to use the collection's authored jokes. Nothing requires a
model, account, download or random prompt. Results are ordinary layout steps: select
one to edit or share it. Stop retains finished results.

Use **Save a reusable recipe** to capture a completed selected step. Edit the same
controls used by Run tool, keep the controls, name the recipe and save it. Append
another completed step for a longer recipe. `$input` means the new picture;
`$step0` means the first recipe result. Run on up to 12 pictures / 60 total tool steps.
Recipes live in the project; save the `.badshop` file to retain them.

## Pass the edit on

In **Export → Let someone remix this**, inspect every included picture. Export creates
a new `.badshop` file in the configured output folder. It contains the selected result
and the local edits and images needed to recreate it, without conversations, other
branches, original photo containers or filenames. Source credits are opt-in and shown
before export. Faces, visible words and the text used by edits remain visible. Custom
font steps must use the default font and be replayed first, or be shared as an image.
Animations are re-encoded; timing is retained but GIF palettes may change.

Send the file yourself. The recipient chooses **Open project**, then changes captions
or uses History controls. Normal project saves and `.badpack` exports contain more
information than this selective remix export; see [privacy](privacy.md).

## Show the process or play together

**Show how it happened** turns 2–12 selected History results into a looping GIF, in
History order. Every frame fits the first picture using nearest-neighbor resizing;
no source photo is included automatically. Choose 100–2,000 milliseconds per frame.
Save the original GIF to preserve animation; clipboard copy is a still frame.

**Play a remix challenge** saves the current scene as a common starting point. Name
the challenge, then each player. Start a player's round, edit normally, then start
the next player's round from that same scene. Reveal the takes and award stars.
Each challenge supports eight rounds. Save/reopen keeps all rounds and stars.
This is a pass-and-play activity on one computer. For an asynchronous challenge,
send an editable remix and exchange finished images or returned projects.

There is no automatic upload, public feed, online lobby or score service.
