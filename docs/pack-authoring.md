# Share a character collection

A useful first contribution is three to eight original characters or expressions
that work together: a disastrous office, a tiny local newspaper, or petty victories.
Give the collection a specific comedic premise and recognizable roles.

1. Use pictures you created, public-domain material or appropriately licensed assets.
   Record creator, source URL, license and required attribution. Unknown rights are
   not permission. Keep consent and private information in mind for photographs.
2. Import each picture and prepare a hard-edged cutout if useful. Under **Your cast
   of characters**, select it, set a character name, expression and collection, and save.
3. Try the collection in three Quick ideas. Check the joke at the 320-pixel export
   preview. Use expressions and names that remain understandable without a long prompt.
4. Filter the cast to that collection and export it. Review the included originals
   and source metadata: `.badpack` is a reusable asset archive, not a privacy filter.
5. Import the pack into a fresh temporary library/profile and use a character in a
   new project. Keep a preview image and the exact app version used for this check.
   Never delete your real library to simulate a fresh installation.

To propose inclusion, open an issue with the premise, preview, names, source/license
table, minimum tested version and any required attribution. Share only reviewed files.
Pack files are declarative image/data archives; do not add scripts or executable code.
For the format and existing built-ins see [layouts and packs](layouts-and-packs.md).

For a reusable editing recipe, capture and save steps in a small example project.
Only use local tools. Explain which controls should change and how `$input` and earlier
step outputs connect. Share a reviewed project with non-private sample images; selective
remix export shares the selected edit chain, not the saved recipe catalog.
